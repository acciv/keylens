# 🔍 keylens

привет. это моя первая прога на питоне. она ищет ключи в файлах.

типа если ты случайно залил ключ в гитхаб и потом сидишь и думаешь "ой всё, кажется я облажался" — вот оно помогает его найти. не всегда находит но старается. я проверял на своём коде, там оно нашло 2 штуки и я прям обрадовался.

## зачем это вообще

ну я же не идеальный, могу забыть и сунуть `API_KEY = "сампонимаешьчто"` в файл. а потом кто-то увидит и... в общем плохо. вот я и сделал сканер. мама сказала пусть будет полезная прога, а не только игры.

## что оно ищет

- гитхабные ключи (`ghp_`, `github_pat_`) — у меня один такой уже был, не спрашивайте
- aws (`AKIA...`)
- слак (`xoxb...`)
- openai (`sk-...`)
- телеграм ботов
- приватные ключи (такие `-----BEGIN...`)
- и просто строки типа `secret = "..."`

## как запускать

если у тебя питон есть (у меня 3.14, он новый и немного страшный):

```bash
python -m keylens scan .
```

или если установил:

```bash
pip install .
keylens scan ./папка
```

он показывает ключ НЕ целиком, а типа `ghp_...cdef`, потому что я не хочу чтобы ещё один ключ утёк. иронично да.

## флаги (я их долго придумывал)

```bash
keylens scan . --json          # если хочешь красиво в json, я не знаю зачем но есть
keylens scan . --exclude vendor
keylens scan . --max-size 5    # если файл большой и ленивый
```

## коды возврата

| код | что значит |
| --- | ---------- |
| 0 | всё чисто, можно жить дальше |
| 1 | нашёл ключ, иди ротируй его |
| 2 | ты не туда путь написал |

это можно в CI пихать, чтобы коммит с ключом не проходил. я сам не пробовал, но вроде работает.
